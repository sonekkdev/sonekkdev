### sonekk

I build developer tools for VR and Unity, and give them away to small studios.

**The anti-cheat stack** ([one repository](https://github.com/sonekkdev/sonekk-anticheat))

| # | Project | What it does |
|---|---|---|
| 1 | [guard](https://github.com/sonekkdev/sonekk-anticheat/tree/main/guard) | Device integrity: root, Frida, hooks, runtime patches, hardware attestation |
| 2 | [motion](https://github.com/sonekkdev/sonekk-anticheat/tree/main/motion) | Movement validation: speed, flight, teleports, false grounding, kick and ban ladder |
| 3 | [seal](https://github.com/sonekkdev/sonekk-anticheat/tree/main/seal) | APK integrity: repacked builds, injected libraries, patched natives |
| 4 | [antiadb](https://github.com/sonekkdev/sonekk-anticheat/tree/main/antiadb) | ADB activity during a session, without banning developer mode |

**Apps and tools**

| Project | What it does |
|---|---|
| [sonekks-chat](https://github.com/sonekkdev/sonekks-chat) | Desktop AI chat and agent with tool approvals, attachments and cost meters |
| [sonekk-chat-android](https://github.com/sonekkdev/sonekk-chat-android) | The same app on Android, WebView plus a Kotlin bridge |
| [sonekk-chat-ios](https://github.com/sonekkdev/sonekk-chat-ios) | The same app on iPhone, unsigned IPA for kSign |
| [sonekk-sweep](https://github.com/sonekkdev/sonekk-sweep) | Map checker that finds missing colliders, fall-through floors and open edges |
| [sonekk-xray](https://github.com/sonekkdev/sonekk-xray) | Unity project dependency graph: what references this, what breaks, what is dead weight |

Everything here is source available and free for companies under 100 people and under 1M USD revenue.
